# Ghost Drawer Device

A low-power ATtiny1616-based sound device designed to hide inside a drawer and randomly play a ghost-like sound when the drawer is opened.

The project originally started as a Raspberry Pi Pico prototype and was later migrated to an ATtiny1616 to reduce idle current and improve battery life.

---

## Current Hardware

- ATtiny1616 breakout
- Photoresistor
- 10 kΩ resistor
- Passive buzzer
- Momentary push button
- Debug/status LED
- Battery power
- UPDI programmer

## Current Functionality

The device is designed to sit inside a closed drawer and remain in a low-power sleep state until activity is detected.

The ATtiny1616 wakes approximately every 250 ms, briefly powers the photoresistor circuit, checks the light level, and then returns to sleep.

---

## Drawer Trigger

The photoresistor is used to detect a sudden increase in light when the drawer is opened.

Current light-detection settings:

```cpp
const int CHANGE_THRESHOLD = 75;
const int TRIGGER_CONFIRM_COUNT = 2;
const int COOLDOWN_WAKE_COUNT = 4;
const int BASELINE_SAMPLE_COUNT = 4;
```

A possible drawer opening must exceed the light-change threshold on two consecutive sensor readings before it is accepted as a valid trigger.

This helps reject short spikes or unstable ADC readings.

The current detection sequence is:

```text
Normal baseline
      ↓
Light increases by at least +75
      ↓
First qualifying reading
      ↓
Second qualifying reading
      ↓
Confirmed drawer event
      ↓
Random sound decision
      ↓
Approximately 1 second cooldown
      ↓
Take 4 fresh sensor readings
      ↓
Establish new baseline
      ↓
Ready again
```

The device no longer requires the light level to fall by a specific amount before re-arming.

Instead, it automatically establishes a new baseline after the cooldown period.

---

## Adaptive Baseline

While the device is armed and no trigger is detected, the light baseline slowly follows gradual changes in ambient lighting.

The current baseline update is:

```cpp
baseline =
  (
    baseline * 15L +
    lightValue
  )
  / 16;
```

This allows the sensor to adapt slowly to environmental changes without immediately following a sudden drawer-opening light change.

## Debug LED

Pin 4 currently drives a temporary debug/status LED.

Current behavior:

```text
LED OFF
=
Sensor armed and ready

LED ON
=
Confirmed light trigger / cooldown active
```

The LED is being used to verify real-world trigger behavior during testing.

It is intended to be removed from the final version once the light-detection behavior is considered stable.

## Random Sound Behavior

Each confirmed drawer opening has a chance of playing a sound.

Current setting:

```cpp
const int SOUND_CHANCE = 4;
```

This gives the device a:

**25% chance of making a sound on each confirmed drawer opening**

If a sound is selected:

- **49/50 chance** — regular ghost sound
- **1/50 chance** — rare crazy ghost sound

Approximate probability per confirmed drawer opening:

```text
75%    No sound
24.5%  Regular ghost sound
0.5%   Crazy ghost sound
```

---

## Regular Ghost Sound

The regular ghost sound lasts approximately 12 seconds.

It uses hardware PWM generated by TCA0 and includes:

- Smooth pitch transitions
- Alternating high and low tones
- 7 Hz vibrato
- Smooth pitch glide
- Approximately 523 Hz high pitch
- Approximately 466 Hz low pitch

Current main sound settings:

```cpp
const float BASE_FREQ = 523.0;
const float LOW_FREQ  = 466.0;

const float NORMAL_DURATION = 12.0;

const float PITCH_INTERVAL = 2.5;

const float VIBRATO_FREQ = 7.0;
const float VIBRATO_DEPTH = 0.03;

const float GLIDE_TAU = 0.3;

const int UPDATE_MS = 5;
```

A passive buzzer is required because the ATtiny generates the changing audio frequency directly.

An active/self-driven buzzer is not suitable because it contains its own oscillator and may produce a constant shrill tone instead of reproducing the programmed pitch changes.

---

## Crazy Ghost Sound

The rare alternate sound is intentionally much more dramatic.

It:

- Starts near the normal ghost frequency
- Continuously rises in pitch
- Accelerates upward near the end
- Uses increasingly intense vibrato
- Abruptly drops to a low tone after approximately 10 seconds
- Holds the low tone for the final 2 seconds

The crazy ghost sound is intentionally rare so that it acts as a hidden surprise.

Current random selection:

```cpp
const int FUNNY_SOUND_CHANCE = 50;
```

This means that once a sound event has already been selected, there is a 1-in-50 chance that the crazy sound will play.

---

## Push Button

The push button provides a manual trigger independent of the photoresistor.

A normal button press immediately plays the regular ghost sound.

The button also includes a hidden multi-press feature.

During the first 2 seconds of the manually triggered regular ghost sound, additional button presses are counted.

Current settings:

```cpp
const unsigned long SECRET_WINDOW_MS = 2000;
const unsigned long BUTTON_DEBOUNCE_MS = 80;

const int SECRET_PRESS_COUNT = 5;
```

Pressing the button enough times during the secret window interrupts the regular ghost sound and immediately starts the crazy ghost sound.

This provides a way to demonstrate the rare sound without waiting for the random 1-in-50 selection.

## Photoresistor Circuit

The photoresistor and 10 kΩ resistor form a voltage divider.

```text
Pin 3
  |
Photoresistor
  |
  +---- Pin 0 / A0
  |
10 kΩ
  |
 GND
```

Pin 3 powers the sensor only while a measurement is being taken.

This reduces idle current compared with powering the divider continuously from the 3V rail.

---

## Sensor Power Gating

The photoresistor voltage divider originally remained powered continuously.

To reduce idle current, the top of the photoresistor was moved from the 3V rail to GPIO Pin 3.

The sensor is now only powered briefly when a measurement is required.

Each normal light measurement follows this sequence:

```text
Power-down sleep
      ↓
RTC wake
      ↓
Pin 3 HIGH
      ↓
Wait 2 ms
      ↓
Discard first ADC reading
      ↓
Take second ADC reading
      ↓
Pin 3 LOW
      ↓
Process sensor data
      ↓
Return to sleep
```

The first ADC conversion is discarded after sensor power-up and the second conversion is used as the actual measurement.

The sensor is then immediately powered back off.

The ATtiny wakes approximately every 250 ms while the photoresistor circuit is powered for only a small fraction of that time.

---

## Fresh Baseline

After a confirmed light trigger and cooldown period, the firmware establishes a new light baseline.

Current setting:

```cpp
const int BASELINE_SAMPLE_COUNT = 4;
```

Four sensor readings are averaged together to create the new baseline.

This allows the device to adapt to the current drawer/light condition rather than relying on a fixed ADC threshold.

## Low-Power Operation

Idle current was one of the main design challenges in this project.

Early versions used a Raspberry Pi Pico and consumed roughly:

```text
17–18 mA idle
```

This was too high for a device intended to stay powered inside a drawer for long periods.

After migrating to the ATtiny1616 and adding power-down sleep and sensor power gating, recent measurements have typically been around:

```text
0.2–0.3 mA idle
```

Measured current can fluctuate somewhat depending on wake timing and meter response.

Main low-power techniques include:

- ATtiny1616 power-down sleep mode
- RTC wake approximately every 250 ms
- Photoresistor powered only during measurements
- Sensor power supplied from GPIO Pin 3
- 2 ms sensor settling period
- First ADC conversion discarded
- Sensor immediately powered off after each reading
- Low-power ATtiny1616 architecture
- Unnecessary breakout-board indicator LED removed

---

## Battery Power

The current prototype can be powered from two AA batteries.

A fresh 2×AA alkaline pack is approximately:

```text
3.0–3.2 V
```

At an idle current of roughly 0.2–0.3 mA, the device is expected to operate for many months under normal use.

Actual battery life depends on:

- Battery capacity
- Battery chemistry
- Number of sound events
- Buzzer current
- Temperature
- Battery self-discharge
- Minimum voltage at which the complete circuit remains reliable

The original project goal was at least 30 days of operation, which the current ATtiny1616 version should comfortably exceed.

---

## Power Switch

A simple SPDT switch can be used as the main power switch.

For a three-pin switch with the center pin as common:

```text
Battery +  → center switch pin
VIN        → one outer switch pin
Other outer switch pin → not connected

Battery -  → GND
```

The unused outer switch terminal can be swapped with the VIN terminal if the desired ON/OFF physical direction is reversed.

## Programming

The ATtiny1616 is programmed using an Adafruit High Voltage UPDI Friend and the Arduino IDE with megaTinyCore.

Current configuration:

```text
Chip:       ATtiny1616
Clock:      10 MHz internal
Programmer: SerialUPDI
Baud:       57600
```

### UPDI Connections

When the UPDI Friend is powering the target:

| UPDI Friend | ATtiny1616 |
|---|---|
| White | UPDI |
| Black | GND |
| Red | VIN |

When the battery is powering the ATtiny1616 during programming:

| UPDI Friend | ATtiny1616 |
|---|---|
| White | UPDI |
| Black | GND |
| Red | Disconnected |

Do not power the board simultaneously from both the battery and UPDI Friend unless the power arrangement has been specifically designed for that condition.

A direct ground connection between the programmer and ATtiny board is recommended for reliable UPDI communication.

## Project Goals

The main goals of the project are:

- Long battery life
- Small physical size
- Low idle current
- Reliable drawer-opening detection
- Fast response to drawer opening
- Randomized sound behavior
- Rare hidden alternate sound
- Manual sound trigger
- Simple standalone operation

The final device is intended to remain hidden inside a drawer for long periods and occasionally surprise whoever opens it.
